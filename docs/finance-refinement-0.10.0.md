## Підтверджені групи продавців

«Витрати → Усі продавці · пошук і групи → Налаштувати об’єднання назв». Обери оригінальні назви, введи спільне ім’я й підтвердь об’єднання. Пошук показує записи вибраного періоду; редактор груп охоплює всі категорії цього періоду. Збережені правила можна скасувати.

Група змінює лише подання статистики. Оригінальні описи банку, ID, категорії, суми та прив’язки не переписуються. Фільтр групи відкриває всі її оригінальні назви; старі посилання на точний опис залишаються точними. Вкладені й циклічні групи відхиляються. Правила використовує також `finance.query(view="analytics")`.

## Межі й навантаження

Порівняння перед найдавнішим збереженим записом або поза строком банківської історії не отримує відсоткової оцінки. Наявність раннього запису не доводить повноту імпорту: пропуски виписки потрібно звіряти з банком. Дні без записаних витрат не є доказом відсутності реальних витрат.

Зберігаються попередні межі: 366 днів за один звіт, до 40 000 записів у спільному вікні підрахунку, операції по 50, приватний API без HTTP-кешування. Каталог продавців обчислює всі назви в цьому вікні, повертаючи лише одну сторінку. Пошук має коротку затримку перед запитом, кеш Mini App — 60 секунд. Для графіків не викликаються моделі або Monobank. Оновлення банку запускається явною дією та має спільний стан.

Бюджети, графіки боргів і баланси — чинний стан; нове зберігання щоденних знімків не додано. Прогноз використовує введені плани та не виконує списань. Невідомі суми не підставляються як достовірні нулі.

## Реліз

Root/Mini App: 0.10.0. Expand-міграція `0041_finance_merchant_aliases.sql` додає JSON налаштувань підтверджених груп. Читання сум і старі клієнти сумісні без цього поля; запис правил потребує застосованої міграції. Секрети та зовнішні дозволи не змінюються. Оновлення конфігурації захищене версією й повторним ID команди, як інші фінансові дії.
