# Новини · 0.30.0

Погоджені відповіді власника: спільна стрічка всіх тем, збережені режими з видимими категоріями, компактні картки, короткі деталі та всі доступні свіжі матеріали порціями. На картку винесені дві дії: зберегти для подальшого читання й стежити за продовженням події.

## Поведінка

- Початковий режим «Стрічка» об’єднує доступні теми за часом публікації, новіші зверху. «Головне» зберігає редакторський порядок пріоритетних матеріалів; «Інтереси» й «Стежу» залишаються окремими режимами. Повернення зі статті та переходи між вкладками відновлюють поточний перегляд у межах сесії.
- Категорії видимі одразу під режимами й гортаються горизонтально. Порядок сталий: Україна, Світ, Технології, Наука, CS2, Футбол; інші теми — далі. Показані лише теми доступних матеріалів поточного режиму або збереженого. «Світ» і «Технології» — короткі підписи чинних категорій, серверні ключі не змінені.
- Зміна режиму скидає категорію на «Усе». Лічильник нових/оновлених враховує категорію та пошук. Якщо нова застосована добірка більше не містить обраної категорії, вона залишається видимою, щоб читач міг явно її скинути. Пошук, відновлений із сесії, відкритий одразу.
- Картка містить заголовок, до двох рядків додаткового змісту та невелике фото за наявності. Збереження й стеження — окремі від відкриття кнопки, які не позначають матеріал прочитаним і не надсилають вподобання. Збереження має оптимістичний стан із відкотом помилки; стеження змінюється після підтвердження сервера. Давня закладка без відомої історії не пропонує недоступного стеження.
- Спочатку відкриті шість карток; наближення до кінця відкриває наступні шість, доки є матеріали. Кнопка «Ще події» доступна для клавіатури та WebView без IntersectionObserver. Спостерігач від’єднується після одного спрацювання й при виході зі стрічки. Усі картки належать уже отриманій добірці: гортання не запускає RSS-збір, переклад або редактора. Архів давніх збережень зберігає окрему явну пагінацію.
- Старі налаштування перегляду v2 скинуті один раз новим ключем v3, щоб попередній прихований фільтр не перекрив погоджений початковий режим. Реальні збереження, стеження та прочитання не скидаються.

Деталі з короткими фактами й переходом до оригіналу збережені. Джерела, серверні ліміти добірки (до 18 подій), бюджет редактора й переклад не змінені. «Усі доступні» означає всю отриману добірку, без додаткової межі інтерфейсу; це не весь RSS-архів видань. Нових залежностей, секретів або міграцій немає.

## Перевірки

Сценарії охоплюють спільну стрічку та два тематичні режими, видимі категорії, контекстний лічильник, зниклу категорію після оновлення, збереження з відкотом, стеження після підтвердження та відкриття понад 18 карток порціями. Застарілі виклики спостерігача ігноруються. Чинні сценарії деталей, стабільного застосування добірки, архіву й справжніх хуків у StrictMode залишаються.

Для публікації перевіряються типи, лінтер, повний dashboard-набір, production-збірка та CI; вручну — 320/393 px, обидві теми, категорії, дії й повернення зі статті. Основна зміна — у React Mini App; контракт приватного API сумісний із 0.29.0.
