Повідомлення у прикладах - цільовий формат (persona.md).

## N3. Швидка смуга - правила маршрутизації

Тривіальним вважається текст, якщо ВСІ умови: ≤ 120 символів; немає слів-якорів власних даних (`мій`, `моя`, `мої`, `календар`, `пошта`, `лист`, `нагадай`, `запиши`, `збережи`, `знайди в`, `покажи`, `витрат`, `ідея`, `бажан`, `поїздк`, `столик`, `чат`, назви колекцій); немає URL; є число з оператором або питальне слово факту (`скільки`, `коли`, `хто`, `що таке`, `який рік`). Haiku відповідає ≤ 3 рядками або `ESCALATE: <причина>`.

| id     | Вхід                                                       | Очікувано                                                               |
| ------ | ---------------------------------------------------------- | ----------------------------------------------------------------------- |
| S-N3-1 | «скільки 17 % від 4 200»                                   | `quick` → «714 (4 200 × 0,17)» ≤ 4 с                                    |
| S-N3-2 | «якого року заснували Львів»                               | `quick` → «1256 (перша згадка).»                                        |
| S-N3-3 | «коли в мене зустріч»                                      | якір `мене`/`зустріч` → `chat` одразу                                   |
| S-N3-4 | «що таке Durable Object простими словами» (140 симв.)      | довжина > 120 → `chat` (лише час)                                       |
| S-N3-5 | «скільки я витратив учора» (без якоря «мій», але `витрат`) | `chat`                                                                  |
| S-N3-6 | Haiku повертає `ESCALATE`                                  | статус «думаю довше…» → `chat` з тим самим текстом, без дубля відповіді |

## P. План дня (`/plan`, «склади план дня», «що в мене сьогодні»)

Зараз: `/plan` → агент читає календар і пише таймлайн, нічого не зберігає. У новій системі план дня - профіль `chat` з підказкою наміру `day-plan` (prerouter ставить її на `/plan`, «план дня», «план на завтра», «що в мене сьогодні/завтра»). Жодного окремого працівника: усе читається інструментами в одному прогоні; Планувальник залучається лише для маршрутів.
