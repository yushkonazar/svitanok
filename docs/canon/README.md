# Канон асистента - v1

Проєктна документація нового асистента: навіщо він такий, як влаштований, які
рішення й чому ухвалені, що саме мало працювати на кожному етапі. Опублікована
в репозиторії 08.09.2026, після закриття етапу 7 і релізного блоку.

⚠️ Це **зафіксований v1**, а не журнал. Файли описують систему станом на
завершення розробки; усе, що змінилось після, змінюється кодом і фіксується
тут окремим коментарем із датою (як S-0-6 у `04-scenarios.md`). Робочі
чернетки, опитування й ревʼю лишились у `.workspace/Assistant/` і в
репозиторій не входять.
