# Приватний чат як основний дім асистента

Основний чат Svitanok переходить у приватний діалог із ботом. Mini App не змінюється. Супергрупу не видаляємо одразу: старі нагадування і сценарії мають завершитися за адресою створення, а вона може бути темою групи.

## Перед увімкненням

1. Перевірити, що власник уже написав ботові у приватному чаті. Інакше Telegram не дозволить йому надіслати перше повідомлення.
2. У Cloudflare Worker має існувати секрет `TELEGRAM_OWNER_USER_ID` із числовим Telegram user ID власника. Значення не друкувати в логах. `/ready` тепер окремо показує, чи адреса приватної доставки налаштована.
3. У GitHub Actions додати той самий ID як окремий секрет `TELEGRAM_OWNER_USER_ID`. Це не API-ключ і не потребує його ротації. Два API-ключі OpenAI для VPS і Actions можуть залишатися різними.
4. У GitHub Actions створити repository variable `ASSISTANT_HOME=dm`. Без неї Actions зберігає доставку брифінгу в стару групу; Worker використовує значення `ASSISTANT_HOME` зі свого `wrangler.jsonc`.

## Контроль після релізу

- У приватному чаті: `/ready` показує `Доставка: ✅ приватний чат.`; `/start` відображає меню і кнопку Mini App. Повторний setup не дублює закріплене повідомлення.
- Створити тестове нагадування у приватному чаті і дочекатися доставки туди ж. Старе нагадування з групи має прийти в групу.
- Перевірити одне уточнення через кнопку, наприклад тривалість зустрічі: відповідь має стосуватися тієї ж події.
- Перевірити наступний плановий брифінг: він приходить у приватний чат без `message_thread_id`; ранкові помилки Actions теж мають іти туди.
- Некритичний вечірній фінансовий рядок та підказки про старі ідеї/сценарії у приватному режимі вимкнені типово. Особисті нагадування, близькі списання, поїздки та критичні алерти залишаються.
- Не архівувати супергрупу, доки не завершаться старі сценарії й не перевірено брифінг. Історію групи не видаляти.

## Відкат

Якщо приватна доставка недоступна, повернути Worker `ASSISTANT_HOME=group` і GitHub Actions variable `ASSISTANT_HOME=group`, потім повторити setup Telegram. Дані та вже створені нагадування не переносити вручну: вони памʼятають первісну адресу.
