# Тижневий пакет · 0.17.2

Після 0.17.1 великий пакет тижневого звіту міг утратити цілі розділи
при скороченні до 50 000 символів, хоча читання всіх джерел було успішним.
Унаслідок цього задачі, фінансовий контекст і чотиритижнева база не доходили
до огляду. Окремий дефект дозволяв вечірній запуск пропущеного повтору
з повідомленням про 12:00.

## Зміни

Скорочення тепер працює всередині кожного розділу: прибирає сирі ряди,
повторні поля й довгі списки прикладів. Зберігаються підсумки джерел,
усі фінансові категорії, підтверджені й очікувані суми, чотири базові періоди,
залишки, платежі, стан банківської звірки, чинні задачі та їхні пояснення.
Скорочені списки мають явні позначки; нестача ліміту навіть для підсумків
повертає явний непридатний пакет, а не огляд із тихо вилученими розділами.

Профіль звіту читає пакет без власного малого `cap`. Некоректний малий ліміт
отримує HTTP 400 і один виправлений повтор через чинний механізм Brain.
Охоплення чек-інів за версіями рахує лише підтверджені слоти в часовому зрізі;
нуль старої анкети не означає відсутності нових відповідей.

Плановий повтор дозволено лише о 12:00–12:59 за Києвом. Повідомлення показує
фактичний час повтору; після 13:00 пропущений запуск не наздоганяється.
Ручна команда звіту залишається доступною. Заголовок часткового огляду
називає конкретні прогалини, зокрема ціни й історію витрат API.
Інструкція забороняє перекладати внутрішні дефекти пакета на власника як задачі.

## Перевірки та сумісність

Регресії перевіряють великий синтетичний пакет, незмінність вхідних даних,
точні фінансові підсумки й чотири бази, задачі з поясненнями, версії анкет,
HTTP 400 → виправлене читання, межу 12:59/13:00 та вечірній тік планувальника.
Окреме локальне відтворення використовує приватну копію даних поза Git;
воно не запускає модель і не надсилає звіт.

Міграцій схеми й переписування користувацьких даних немає. Невідомі ціни,
час старих відповідей чи неповна історія можуть залишати огляд частковим.
Реліз перевіряється через CI, штатний Cloudflare Build, парність інструкції
та захищені читання production API. Відкат повертає попередню Worker version;
відновлення бази для цього виправлення не потрібне.
