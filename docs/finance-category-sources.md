# Категорії фінансів

Станом на 2026-10-04 список містить усі 18 категорій покупок, опублікованих
у [дашборді Monobank](https://monobank.ua/dashboard). Точні назви й ID
отримано з публічного JSON, який використовує цей дашборд:
`https://monobank.ua/api/dashboard/stat/ctgpay?lang=uk`.

Додано «Покупка частинами» і «Розстрочка» — окремі банківські продукти,
які також потрібні для обліку платежів. [Monobank](https://monobank.ua/chast)
використовує назву «Покупка Частинами».

Це не твердження про повний довідник усіх типів операцій приватного застосунку.
[Персональний API](https://api.monobank.ua/docs/index.html) передає `mcc`,
`originalMcc` та опис операції; окремого каталогу назв категорій він не надає.
Категорії кешбеку не використовуються як заміна статистики витрат.

Єдиний каталог для backend і демонстраційного режиму:
`web/core/finance/categories.mjs`. Назви відображення можуть відрізнятися від
історичних значень: «Продукти та супермаркети» зберігається як `продукти`,
«Кафе та ресторани» — як `кафе й ресторани`. Це зберігає зв’язки з бюджетами
та старими операціями без міграції. Попередні деталізовані категорії й власні
категорії залишаються доступними, зокрема категорії вже записаних платежів.

«Покупка частинами» не виводиться автоматично з MCC магазину: він описує
продавця, а не графік погашення. Категорію можна вибрати вручну при створенні
платежу чи уточненні банківської операції. Після прив’язки фактичного списання
до платежу воно отримує категорію цього платежу й не дублюється.
