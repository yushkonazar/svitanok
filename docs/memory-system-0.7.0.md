# Пам’ять і «Система» · 0.7.0

Пам’ять доступна з налаштувань через «Переглянути й упорядкувати записи».
Каталог має пошук, групи та окремі вікна редагування і прибирання. Після
закриття вікна зберігається позиція сторінки. Технічні тестові записи приховані
за замовчуванням; їх можна показати окремо.

Тип відповідає на питання «що це?», категорія - «про що?», зв’язок - «що це
означає для мене?». Наприклад, улюблена страва є вподобанням у категорії їжі,
бажане авто - ціллю, сімейне авто - ресурсом родини, перевірка перед конкретною
поїздкою - окремою подією. Перевірка не є офіційним техоглядом і не засвідчує
стан авто назавжди. Перед збереженням редактор показує сформоване речення.

Новий формат value має schemaVersion=2, type, domain, subject, relation і
необов’язкові details/entityId/properties. Storage kind:key залишається
стабільним для сумісності; тип визначає структурований запис. Уточнення не
створює другу копію. Записи змінюються через чинний атомарний журнал та токен
версії; застаріле підтвердження не перезаписує нові дані. Неперевірені старі
значення позначені як такі, що потребують уточнення. Пошук розмов повертає
історичні згортки і current_facts окремо: видалене або виправлене твердження
не відновлюється зі старої історії.

Рекомендований режим для початку - «Питати перед записом». Для автоматичного
режиму власник сам обирає дозволені категорії. Ця версія не розширює згоду,
не вмикає автоматичне збереження й не додає джерел спостереження. Асистент
користується цими ж фактами; уподобання інших людей не виводяться з вибору
власника. «Прибрати» залишає історію; повне забування - чинний /forget.

«Система» розміщена на другій сторінці нижньої навігації поруч із «Дозвіллям».
Панель доступна лише основному власнику через Telegram. /api/system має
private,no-store та повертає метадані без промптів, повідомлень, результатів
інструментів, сирих помилок провайдерів, ідентифікаторів чатів і секретів.
Огляд містить кешовану перевірку асистента, планувальник, доставку, інтеграції,
працівників, останні 50 прогонів, модельну телеметрію за 30 днів та внутрішні
квоти поточного місяця. Відкриття панелі не викликає платну модель.

Виклики моделі, завершені відповіді й оцінки - різні знаменники. Невідомий
результат не є невдачею; рідкісний працівник не вважається зламаним. Ціна
невідомих викликів не підставляється як нуль. Показано повноту обліку.
Claude SDK передає накопичувальні modelUsage за кожною моделлю: зберігається
останній результат query, а не сума проміжних результатів; агрегат не
рахується повторно. Його вартість є API-еквівалентом, не рахунком підписки.
Невідома цінова основа SDK не видається за точну ціну. За кількох моделей
час окремої моделі невідомий, а не нульовий.

Ця панель не є повним білінгом провайдерів. Нові billing-доступи, зміни строків
зберігання та сповіщень потребують окремого погодження. Квоти відображають
лише облік Світанку; місячні хвилини голосу не означають залишок кредиту
Deepgram. API-витрати інших інструментів не додаються до модельних токенів.
Огляд моделей обмежений останніми 5000 записів, каталог пам’яті - першими 1000
із явним повідомленням про межу. Старі записи без телеметрії не дорисовуються.

Палітра «Теплий ранок» збільшує читабельність темної й світлої тем.
Поля розкладу вирівняні, контролери мають видимий фокус і короткий відгук.
Спокійний режим та prefers-reduced-motion прибирають необов’язковий рух.
Відповіді в чек-іні не перемонтовують секцію і не запускають прокрутку.
