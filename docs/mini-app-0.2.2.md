# Світанок Mini App 0.2.2 — окремі ряди та фіксація карток

Кожен тип активного платежу має власний ряд: «Оплата частинами», «Розстрочки на картку», «Підписки», «Кредити», «Інші платежі». Порожні ряди не показуються. Оплата частинами більше не змішується з розстрочкою на картку.

Усередині ряду записи завжди впорядковані за наступною датою оплати: найближча дата — зліва. Підтвердження оплати переносить наступну дату за графіком і пересортовує ряд; оплачена картка стає після зобов'язань із ближчими датами. Повністю погашені й достроково закриті борги, завершені разові платежі та скасовані підписки зникають з активного списку. Фінансовий облік і графік погашення не змінено.

Карусель тепер фіксується на цілій картці по центру через нативний CSS scroll snap (`mandatory`, `center`, `always`), замість вільного прокручування частинами карток. Вертикальне прокручування сторінки з поверхні картки залишається доступним. Навігація під рядом містить дві стрілки, лічильник та індикатор положення; зайві смуги прокручування приховані. Клавіатура підтримує стрілки, Home та End. При зменшенні руху в налаштуваннях пристрою переходи через кнопки не анімуються.

Зміна порядку чи дати після фінансової дії повертає ряд до найближчого платежу. Звичайне оновлення незмінних даних не скидає поточну картку. Для старих браузерів використовуються стандартні можливості прокручування без спеціальних touch-обробників.

На вкладці фінансів вимкнено нативний вертикальний жест згортання Mini App через `Telegram.WebApp.disableVerticalSwipes` (Bot API 7.7+); при виході з вкладки жест відновлюється. Це не блокує прокручування сторінки та закриття через заголовок Telegram. На старих клієнтах, що не підтримують цей API, вимкнути нативний жест із вебсторінки неможливо. [Документація Telegram](https://core.telegram.org/bots/webapps#initializing-mini-apps).

Міграція даних не потрібна. Регресійні тести перевіряють розділення типів, порядок після зміни дати, приховування закритого запису, відсутність скидання при оновленні незмінних даних, горизонтальну навігацію та вимкнення/відновлення жесту Telegram. Перевірено серверні сценарії оплати й повного погашення, мобільну ширину та демонстраційне підтвердження оплати в браузері.
