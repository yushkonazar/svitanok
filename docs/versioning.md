# Версії Світанку

Стан на 12.10.2026. Існуюча схема нумерації збережена.

- Root package і Mini App: 0.3.11 для релізу моделей; попередній реліз #469 — 0.3.10.
- Brain має незалежну версію 0.1.0. Конкретний artifact визначають repository SHA та release manifest.
- Worker має власний deployment/version ID. Версія пакета не підтверджує deployment.
- Окремої глобальної SemVer для всіх компонентів не запроваджено. Позначки дизайну та roadmap не замінюють версій програмних пакетів.

У звітах називати компонент, SHA та результат живої перевірки. Підготовлені
нерозгорнуті блоки не називати production-функціями. Цей реліз моделей не
містить pending блоку персональної пам'яті чи міграції 0038.
10.10.2026 коміт 35f3266 підняв root з 0.1.0 до 0.2.0 при релізі Mini App.
Далі root і Mini App змінювалися разом до 0.3.9 (a583398). Реліз #469
підняв їх на 0.3.10 (ef2cb7a). Окремої глобальної SemVer у перевіреному коді,
Git tags або GitHub Releases не знайдено. Позначки дизайну v2, роадмепу v3
і версії схеми документів не підміняють версії програмних пакетів.

0.3.10 неточно називати версією всіх компонентів. Публікація нової системи
глобальної нумерації потребує окремого рішення; існуючі числа не відкочуємо
і не переписуємо історію релізів. У звітах називати компонент, SHA і результат
production verification, а не лише «готова нова версія».
